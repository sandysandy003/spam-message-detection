\# Spam Message Detection



A machine learning project that predicts whether a text message is spam or not spam.



\## Technologies Used

\- Python

\- Scikit-learn

\- Streamlit

\- Joblib



\## Project Files

\- `app.py` — Web application

\- `predict\_spam.py` — Command-line prediction program

\- `feature\_extraction\_code.py` — Feature extraction code

\- `spam\_model.pkl` — Trained machine learning model



\## How to Run



Install dependencies:



```bash

py -m pip install streamlit scikit-learn joblib

```



Start the application:



```bash

py -m streamlit run app.py

```



Open the local URL displayed in the terminal.
