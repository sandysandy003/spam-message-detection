# Spam Message Detection

A machine learning project that detects whether a text message is **Spam** or **Not Spam (Ham)**. It uses Python, Scikit-learn, and Natural Language Processing (NLP) techniques to analyze messages and predict spam. The project includes a simple web interface built with Streamlit, allowing users to enter a message and get a prediction.

## Features
- Detects spam and legitimate messages.
- Uses text feature extraction and machine learning.
- Provides an interactive Streamlit web application.
- Displays predictions for user-entered messages.

## Technologies Used
- Python
- Scikit-learn
- NLP and CountVectorizer
- Multinomial Naive Bayes
- Joblib
- Streamlit

## How to Run
1. Install the required dependencies using `pip install -r requirements.txt`.
2. Run the application using `python -m streamlit run app.py`.
3. Enter a message to check whether it is spam or not.

This project is suitable for beginners learning machine learning, text classification, and Python application development.
